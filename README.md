# 🚀 Elite Admin Dashboard

A production-ready, role-based admin dashboard built using React and Redux Toolkit.  
This project demonstrates real-world authentication architecture, protected routing, session management, and advanced dashboard features.

## 🧠 Key Features

### 🔐 Authentication & Authorization
- Role-based access control (Admin, Editor, Viewer)
- Protected routes using React Router v6
- JWT expiry auto-detection
- Silent token refresh logic
- Idle session timeout with 30-second warning modal
- Auto logout on inactivity or token expiry

---

### 📊 Dashboard & Analytics
- KPI cards
- Line chart, Bar chart, Pie chart (Recharts)
- Real-time range filtering
- Professional SaaS-style UI

---

### 👥 Users Management
- Create / Edit / Delete users
- Search & pagination
- Role-based permissions
- Async API simulation with Redux Toolkit
- Toast notifications

---

### 📁 Export Features
- Export to CSV
- Export to Excel (.xlsx)
- Export to PDF
- Print support

---

### ⚙️ Architecture Highlights
- Modular feature-based folder structure
- Service layer abstraction
- Axios interceptor structure
- Redux Toolkit slices
- Custom hooks (session timeout, token expiry)
- Lazy loading with Suspense
- Environment-based configuration (.env)
